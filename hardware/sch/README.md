# Принципиальные схемы и блок диаграммы

## Структурная схема NAS
Start88‑NAS построен на базе 8‑ядерного процессора **RK3588**. Основные функциональные блоки сгруппированы по интерфейсам и назначению: ядро системы, интерфейсы ввода/вывода, подсистема управления питанием, накопители и периферия:

## Подробное описание блоков

### 1. Процессор и память
- **RK3588** — 8‑ядерный процессор (4×Cortex‑A76 + 4×Cortex‑A55).
- **LPDDR4x** — до 32 ГБ, интегрирована в основную шину.
- **eMMC** — до 128 ГБ (подключена через PMUIO 2).

### 2. Накопители (Storage)
- **M.2 M‑key (PCIe Gen3 x2)** — до 2‑х дисков NVMe 2280.
- **M.2 M‑key (PCIe Gen2 x2)** — до 2‑х дисков NVMe 2280.
- **Micro SD** — внешняя карта памяти (uSD push‑pull).

### 3. Сетевые интерфейсы
- **2× GbE Ethernet** — PHY0 и PHY1, оба с поддержкой PoE+ (30 Вт на порт).
- **M.2 E‑key** — для модуля WiFi/BT5 (PCIe + USB).
- **NFC** — NT3H2111, антенна встроена.

### 4. Дисплеи и управление
- **5″ IPS TFT** — MIPI‑DSI, ёмкостный тач.
- **1.29″ OLED** — I2C (служебный дисплей).
- **HDMI 2.0/2.1** — отдельный порт.

### 5. USB‑интерфейсы
- **2× USB3.1 Type‑A** (Host, SS/HS).
- **2× USB3.0** (Host 0, Host1/OTG 1).
- **2× USB2.0** (Host 0, Host 1).
- Все порты имеют защиту **EN_OC**.

### 6. Подсистема PMUIO
Состоит из двух блоков (PMUIO 1 и PMUIO 2), обеспечивающих:
- RTC и температурный датчик.
- До 6 линий GPIO общего назначения.
- Управление питанием eMMC и периферией.

### 7. Микроконтроллер RP2040
Выполняет роль **сервисного процессора**:
- Управление кнопками (Power, Reset, Mode, Set).
- Индикация (Power LED, User LED).
- Пищалка (buzzer).
- Управление вентилятором (4‑pin PWM).
- Мониторинг и управление питанием (PD, PoE+, UPS).

### 8. Дополнительные интерфейсы
- **UART2** — отладочная консоль.
- **UART3, UART4, UART6** — с аппаратным управлением потоком.
- **I2C0, I2C6, I2C7** — для подключения RTC, датчиков, OLED.
- **SPI0** — с 2 линиями Chip Select.
- **CAN0** — промышленный интерфейс.
- **PCIe30x4 CLKREQN** — управление тактированием PCIe.

### 9. Питание
- Основной разъём — **Type‑C PD**.
- Резервное питание — **2× PoE+** (до 30 Вт каждый).
- Встроенный **UPS** на элементах LiFePO₄ или LTO (18650, 4‑10 Вт·ч).

### 10. Кнопки и индикация
- **Power** — внешняя кнопка.
- **Reset** — внутренняя, доступ через отверстие.
- **Mode** — выбор режима работы.
- **Set** — подтверждение действия.
- **Power LED** (зелёный) — статус питания.
- **User LED** (красный) — пользовательский светодиод.

### Схема подключения основных шин

| Блок        | Интерфейс       | Назначение                       |
|-------------|----------------|----------------------------------|
| eMMC        | PMUIO 2        | Основной флеш-накопитель         |
| SSD         | PCIe Gen2/3 x2 | M.2 M-key (NVMe)                 |
| WiFi/BT     | PCIe + USB     | M.2 E‑key                        |
| Ethernet    | RGMII          | 2× GbE PHY                       |
| HDMI        | HDMI 2.0/2.1   | Видеовыход                       |
| MIPI‑DSI    | MIPI‑DSI       | 5″ дисплей                       |
| I2C6        | I2C            | OLED, RTC, датчик температуры    |
| SPI0        | SPI            | Расширение (2 CS)                |
| UART2       | UART           | Отладочная консоль               |
| CAN0        | CAN            | Промышленная шина                |
| GPIO (1..6) | PMUIO 1/2      | Управление периферией            |

### Особенности реализации
- **Разделение питания** — основное (PD) и резервное (PoE+ / UPS) с автоматическим переключением через RP2040.
- **Горячая замена SSD** — поддерживается аппаратным контроллером (при наличии соответствующего драйвера).
- **Два независимых Ethernet‑порта** — могут использоваться как LACP, bridge или отдельные сети.
- **Компактный корпус** — 130×94×28.5 мм без учёта экрана.
- **Отладка** — выведена на отдельный UART и внутренний контактный разъём.
